Projetos em destaque

Aqui estão alguns projetos que desenvolvi para praticar, testar ideias e mostrar um pouco do que venho construindo com tecnologia. Cada projeto representa uma parte da minha evolução como desenvolvedor.

01

AgroGestor

Aplicação Angular para gestão de controle agrícola em modelo SaaS. O sistema foi pensado para fazendas, empresas agrícolas, cooperativas e consultorias que precisam acompanhar talhões, safras, estoque de insumos, operações de campo, produtividade, indicadores financeiros e assinatura em uma plataforma única.

Angular TypeScript SaaS

02

RotaPlus

RotaPlus é uma aplicação Angular para viagens e hotelaria. O projeto une uma vitrine criativa para clientes, com apresentação de hotéis e pacotes de viagem, a uma área ERP separada para administradores acompanharem reservas, custos, receitas e setores da operação.

TypeScript CSS Responsivo Angular

Livraria Digital

Aplicação de e-commerce de livros construída com Angular 21 + SSR. O projeto apresenta um catálogo de livros completo, carrinho de compras persistente, página dedicada de produto e checkout com validações.
